Unit 1: Introduction to Statistics

Data Presentation

Introduction

In this lesson you will study Data Presentation, part of Unit 1: Introduction to Statistics. What statistics is, the kinds of data, how samples are chosen, and how data are displayed.

Learning Objectives

  • Explain Data Presentation in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Data are shown in frequency tables, bar charts, histograms, pie charts and line graphs. The best choice depends on the type of data and the message.

Formula

$$\text{Relative frequency}=\frac{f}{n}\times100\%$$

Worked Example

Step-by-step solution
  1. 40 students, 10 chose Python
  2. Relative frequency = 10/40
  3. 10/40 × 100% = 25%

Real-Life Applications

Surveys, quality checks and dashboards all start with well-collected, well-presented data.
