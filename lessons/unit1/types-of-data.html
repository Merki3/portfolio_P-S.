Unit 1: Introduction to Statistics

Types of Data and Variables

Introduction

In this lesson you will study Types of Data and Variables, part of Unit 1: Introduction to Statistics. What statistics is, the kinds of data, how samples are chosen, and how data are displayed.

Learning Objectives

  • Explain Types of Data and Variables in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Qualitative data describe categories; quantitative data are numbers, either discrete (counts) or continuous (measurements). Levels of measurement are nominal, ordinal, interval and ratio.

Formula

$$\text{Quantitative}=\text{Discrete}\cup\text{Continuous}$$

Worked Example

Step-by-step solution
  1. Shirt size S, M, L is ordinal
  2. Number of siblings is discrete
  3. Height in cm is continuous

Real-Life Applications

Surveys, quality checks and dashboards all start with well-collected, well-presented data.
