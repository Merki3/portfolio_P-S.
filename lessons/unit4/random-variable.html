Unit 4: Probability Distribution

Random Variable

Introduction

In this lesson you will study Random Variable, part of Unit 4: Probability Distribution. Random variables and the distributions that describe them.

Learning Objectives

  • Explain Random Variable in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

A random variable assigns a number to each outcome of an experiment. Its expected value is the probability-weighted average of its values.

Formula

$$E(X)=\sum x\,P(x)$$

Worked Example

Step-by-step solution
  1. X = heads in 2 fair coin flips
  2. P(0) = 0.25, P(1) = 0.5, P(2) = 0.25
  3. E(X) = 0(0.25) + 1(0.5) + 2(0.25) = 1

Real-Life Applications

Modeling system failures, traffic arrivals and defect counts.
