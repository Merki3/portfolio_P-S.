Unit 5: Normal Distribution

Using the Standard Normal Table (Z-table)

Introduction

In this lesson you will study Using the Standard Normal Table (Z-table), part of Unit 5: Normal Distribution. The bell curve, z-scores and the standard normal table.

Learning Objectives

  • Explain Using the Standard Normal Table (Z-table) in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

The Z-table gives the cumulative area to the left of z. For a right-tail area, subtract the table value from 1.

Formula

$$P(Z>z)=1-P(Z<z)$$

Worked Example

Step-by-step solution
  1. Find P(Z > 1.5)
  2. Table: P(Z < 1.5) = 0.9332
  3. P(Z > 1.5) = 1 − 0.9332 = 0.0668

Real-Life Applications

Grading on a curve, quality-control limits and percentile rankings.
