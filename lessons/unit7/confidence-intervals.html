Unit 7: Estimation and Hypothesis Testing

Confidence Intervals

Introduction

In this lesson you will study Confidence Intervals, part of Unit 7: Estimation and Hypothesis Testing. Estimating parameters and testing claims with sample data.

Learning Objectives

  • Explain Confidence Intervals in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

A confidence interval is a range of plausible values for a parameter at a stated confidence level. The critical value is z = 1.96 for 95%.

Formula

$$\bar{x}\pm z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}}$$

Worked Example

Step-by-step solution
  1. x̄ = 80, σ = 10, n = 25 so SE = 2
  2. Margin = 1.96 × 2 = 3.92
  3. Interval = (76.08, 83.92)

Real-Life Applications

Deciding whether a new algorithm is really faster, or whether a treatment actually works.
