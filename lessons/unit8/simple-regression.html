Simple Linear Regression

Introduction

In this lesson you will study Simple Linear Regression, part of Unit 8: Correlation and Regression. Measuring and modeling the relationship between two variables.

Learning Objectives

  • Explain Simple Linear Regression in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Simple linear regression fits the straight line that minimizes the squared errors, to predict y from one variable x.

Formula

$$b=\frac{n\sum xy-\sum x\sum y}{n\sum x^2-(\sum x)^2},\qquad a=\bar{y}-b\bar{x}$$

Worked Example

Step-by-step solution
  1. Use the data x = 1, 2, 3 and y = 2, 4, 6
  2. b = 12/6 = 2
  3. x̄ = 2 and ȳ = 4
  4. a = 4 − 2(2) = 0

Real-Life Applications

Predicting sales, energy use or grades from related variables.
