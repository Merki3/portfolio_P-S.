Unit 9: Statistical Software Application (Excel/SPSS)

Correlation Analysis

Introduction

In this lesson you will study Correlation Analysis, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Correlation Analysis in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

In Excel use =CORREL(X, Y) or the Data Analysis Correlation tool. In SPSS use Analyze, Correlate, Bivariate. Read the coefficient r and the Sig. (p) value.

Formula

$$r=\text{CORREL}(X,Y)$$

Worked Example

Step-by-step solution
  1. Output: r = 0.78 and Sig. (2-tailed) = 0.001
  2. |r| = 0.78 is a strong positive relationship
  3. 0.001 < 0.05, so the correlation is significant

Real-Life Applications

Analysts use these tools every day to turn raw data into reports.
