Data Entry and Management

Introduction

In this lesson you will study Data Entry and Management, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Data Entry and Management in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Enter one variable per column with a clear header and one case per row. Code categories (1 = Male, 2 = Female) and check for missing or out-of-range values.

Formula

$$n=\text{COUNT}(B2{:}B41)$$

Worked Example

Step-by-step solution
  1. Scores are typed in B2 to B41
  2. =COUNT(B2:B41) returns n = 40
