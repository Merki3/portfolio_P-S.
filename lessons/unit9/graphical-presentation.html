Graphical Data Presentation

Introduction

In this lesson you will study Graphical Data Presentation, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Graphical Data Presentation in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

In Excel use Insert, Charts (histogram, column, scatter). In SPSS use Graphs, Chart Builder. Always title the chart and label both axes with units.

Formula

$$\text{number of bins}\approx\sqrt{n}$$

Worked Example

Step-by-step solution
  1. n = 40 scores
  2. Bins ≈ √40 ≈ 6
  3. Class width = range/6
  4. Build the histogram with 6 bars
