Unit 9: Statistical Software Application (Excel/SPSS)

Interpretation of Statistical Output

Introduction

In this lesson you will study Interpretation of Statistical Output, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Interpretation of Statistical Output in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Read output in order: sample size, descriptive values, test statistic, p-value (Sig.). Then state the conclusion in plain words, with context.

Formula

$$p\le\alpha\Rightarrow\text{significant}$$

Worked Example

Step-by-step solution
  1. Output: R Square = 0.61 and Sig. = 0.002
  2. Hours studied explains 61% of the variation in scores
  3. 0.002 < 0.05, so the model is significant

Analysts use these tools every day to turn raw data into reports.
