Unit 9: Statistical Software Application (Excel/SPSS)

Introduction to Excel/SPSS

Introduction

In this lesson you will study Introduction to Excel/SPSS, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Introduction to Excel/SPSS in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Excel is a spreadsheet for quick analysis, and SPSS is dedicated statistical software with menus for tests. Both read a table where rows are cases and columns are variables.

Formula

$$\text{rows}=\text{cases},\qquad \text{columns}=\text{variables}$$

Worked Example

Step-by-step solution
  1. Excel: enable File, Options, Add-ins, Analysis ToolPak
  2. SPSS: Data View holds values and Variable View holds names, types and labels
  3. Both programs expect one case per row

Real-Life Applications

Analysts use these tools every day to turn raw data into reports.
