Regression Analysis

Introduction

In this lesson you will study Regression Analysis, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Regression Analysis in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

In Excel use Data Analysis, Regression. In SPSS use Analyze, Regression, Linear. The output lists the coefficients, R Square and p-values.
