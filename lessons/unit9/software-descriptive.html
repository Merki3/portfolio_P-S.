Unit 9: Statistical Software Application (Excel/SPSS)

Descriptive Statistics

Introduction

In this lesson you will study Descriptive Statistics, part of Unit 9: Statistical Software Application (Excel/SPSS). Doing the analysis in Excel and SPSS and reading the output.

Learning Objectives

  • Explain Descriptive Statistics in your own words.
  • Use the key formula in a worked example.
  • Interpret the result in a real situation.

Explanation and Key Definitions

Excel's Descriptive Statistics tool and SPSS's Analyze, Descriptive Statistics, Descriptives report the mean, standard deviation, minimum and maximum in one table.

Formula

$$\bar{x}=\text{AVERAGE}(X),\qquad s=\text{STDEV.S}(X)$$

Worked Example

Step-by-step solution
  1. Output: N = 40, Mean = 78.4, Std. Deviation = 6.2
  2. The typical score is about 78
  3. Most scores fall within about 6 points of the mean

Real-Life Applications

Analysts use these tools every day to turn raw data into reports.
